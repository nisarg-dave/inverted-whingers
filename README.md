## The Inverted Whingers
This is the website for The Inverted Whingers, a football podcast that dives deep into the beautiful game. From player debates to controversial takes on the sport, it covers it all with passion and a healthy dose of skepticism.

### Tech Stack
TanStack Start (SSG)
Tailwind CSS
shadcn-ui

### Infrastructure
Deployed to AWS S3 + CloudFront using AWS CDK
